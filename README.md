# 🌤️ Weather App

A simple and elegant weather application that provides real-time weather updates for any location around the world. Whether you're planning a trip or just deciding what to wear, this app has you covered!

## 🚀 Features

- 🌍 Search weather by city name
- 📍 Get weather based on your current location
- 🌡️ View current temperature, humidity, and Air Quality Index.
- 📝 Provides an overall description
- 🎨 Clean and responsive UI
- 🌙 Light & Dark mode support

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, Bootstrap.
- **Backend**: JavaScript.
- **API**: WeatherAPI (via RapidAPI).
- **Location Services**: Geolocation API
